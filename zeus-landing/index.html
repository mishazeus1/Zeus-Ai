Вопросы

Коротко о главном

Код и проект принадлежат мне?

Да. В любой момент скачайте автономный HTML со встроенными шрифтами и картинками или заберите чистый проект React + Vite + TypeScript в свой GitHub.

Нужно ли уметь программировать?

Нет — достаточно описать задачу словами. Разработчики подключают ZEUS по MCP и работают из своей IDE.

Что такое кредит и на сколько его хватает?

Кредит — единица работы ИИ. Небольшая правка («сделай кнопку крупнее») стоит около 1 кредита, новый проект с нуля — 10–20. 300 кредитов тарифа «Старт» обычно хватает на запуск и месяц доработок одного сайта.

Что будет, если кредиты закончатся?

Сайт продолжит работать и принимать заказы. Остановятся только новые генерации — докупите пакет или дождитесь следующего месяца.

Как принимать оплату на сайте?

Подключите ЮKassa по Shop ID и ключу — и на сайте появятся СБП и карты. Для Mini App доступны Telegram Stars. ZEUS не берёт комиссию с продаж, эквайринг — по тарифу платёжного сервиса.

Как оплатить ZEUS из России?

СБП (QR любого банка), карты Мир / Visa / Mastercard или счёт для ИП и ООО по ИНН с закрывающими документами.

Можно подключить свой домен?

Да, на любом платном тарифе. Добавьте домен, пропишите CNAME у регистратора — ZEUS проверит DNS и выпустит TLS-сертификат.

Как отменить подписку?

В настройках аккаунта в один клик. Доступ сохраняется до конца оплаченного периода, проекты остаются у вас.
