# ZEUS — лендинг и студия (статический прототип)

Самостоятельный сайт без сборки: открыть `index.html` или раздать папку как статику (GitHub Pages, Nginx).

- `index.html` — лендинг: первый экран с Зевсом и 3D-кольцом (Three.js), погружение в примеры, тарифы, FAQ.
- `studio.js`, `studio.css` — студия: бриф → вёрстка → живое превью, правки чатом, ПК/телефон, код.
- `images.js`, `lib/` — фотобанк ZEUS и подстановка фото в сгенерированные страницы (`data-img`, `data-bg`).
- `examples*.js`, `examples.css`, `ex/` — интерактивные примеры проектов.

Генерация в студии работает через Claude только при просмотре внутри claude.ai; вне его студия собирает демо из готовых примеров.
Для боевой версии подключите генерацию к серверу ZEUS (см. `artifacts/` в этом репозитории).
